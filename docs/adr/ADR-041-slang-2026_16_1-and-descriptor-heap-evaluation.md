# ADR-041 — Slang v2026.16.1 Pin and Descriptor-Heap Compiler Foundation

**Status:** Superseded for compiler identity by ADR-047; historical rationale retained  
**Date:** 2026-09-04  
**Supersedes:** the Slang v2026.14 artifact identity in ADR-034  
**Later updates:** ADR-045 / Baseline 036 supersedes the descriptor-buffer-first production policy; ADR-047 / Baseline 039 supersedes this ADR as the current Slang compiler pin authority.

## Decision

Update the project shader compiler pin to:

```text
Slang v2026.16.1
artifact: slang-2026.16.1-linux-x86_64-glibc-2.27.tar.gz
SHA-256: aa213ac457851fa445a5fa1e6b9aac50e06333c692c4c000e05eb2cc321bace9
runtime dependency: none
```

The same acquisition policy remains: verified official prebuilt artifact for normal bootstrap, same-release source build only as fallback, no runtime Slang dependency.

## Rationale

The current Slang release adds/contains the Vulkan descriptor-heap path needed for modern bindless evaluation:

```text
SPV_EXT_descriptor_heap lowering
spvDescriptorHeapEXT compiler capability
ResourceDescriptorHeap[] direct indexing
SamplerDescriptorHeap[] direct indexing
resource/sampler heap stride controls
unified resource-heap stride option
```

Mesa 26.2.0 enabled `VK_EXT_descriptor_heap` by default on ANV, and the developer's post-upgrade Mesa 26.2.2 `vulkaninfo` now confirms the extension, `descriptorHeap = true`, `descriptorHeapCaptureReplay = true`, and the complete heap-property block on the actual Arc B580.

## Descriptor-heap status

ADR-045 / Baseline 036 accepts `DESCRIPTOR-HEAP-001`: this Slang release is now the production shader compiler foundation for the descriptor-heap renderer from initial implementation.

`ufo-shaderc` requests `spvDescriptorHeapEXT` and the unified image/buffer resource-heap stride mode defined by architecture 089.

## Upgrade validation

The Slang upgrade requires:

```text
shader ABI/reflection regeneration
column-major fixture pass
spirv-val pass for all package variants
pipeline/shader cache invalidation by compiler identity
B580 shader/pipeline timing comparison
descriptor-heap compiler conformance fixtures
```

No existing `.rshader` cache generated by v2026.14 is reusable as v2026.16.1 identity.
